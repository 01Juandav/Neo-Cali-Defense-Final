# Neo-Cali Defense

## Descripción

Juego Tower Defense ambientado en Neo-Cali en el año 2089.

## Funcionalidades

- Múltiples tipos de torres
- Diferentes enemigos
- Sistema de oleadas
- Jefe final
- Pantallas de victoria y derrota
- Sistema de puntuación

### Mejoras implementadas
- Mejora de la interfaz gráfica y del diseño visual del juego.
- Adición de un segundo nivel para ampliar la experiencia de juego.
- Implementación de botón de pausa para controlar la partida.
- Implementación de botón de reinicio para comenzar una nueva partida sin recargar manualmente.
- Optimización de la experiencia de usuario mediante menús y navegación más intuitiva.


## Cómo ejecutar

1. Descargar el archivo entrega1_tower_defense.html
2. Abrirlo en Google Chrome o Microsoft Edge

También puede ejecutarse desde Visual Studio Code utilizando Live Server.
